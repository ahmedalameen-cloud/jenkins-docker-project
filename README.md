# AWS DevOps CI/CD Pipeline with Jenkins, Docker & Nginx

## Project Overview

This project demonstrates an end-to-end CI/CD pipeline for deploying a web application using GitHub, Jenkins, Docker, Nginx, and AWS EC2.

## Architecture

GitHub
↓
Jenkins
↓
Docker
↓
AWS EC2
↓
Nginx
↓
Live Web Application

## CI/CD Result

A code change pushed to GitHub can be deployed to the AWS EC2 server through the Jenkins pipeline.

The deployment was successfully tested using Jenkins, Docker, Nginx, and AWS EC2.
